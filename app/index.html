SealedSwarm

Sealed-bid GPU auctions for AI agent swarms

Agents buy compute from each other without showing their hand. Every bid is encrypted and compared on-chain without being opened. A vault on NEAR decides what each agent is allowed to sign, so a hijacked agent can't spend anything. Only the winner and the price are ever revealed.

2Your swarm vault on NEAR

A NEAR contract you own. Each agent is a NEAR sub-account of the vault (atlas.ssvault-you.testnet, …) whose only key can call request_sign on the vault, nothing else. The vault checks every request against your policy (approved auction contract, placeBid/joinPool/submitPool only, no ETH, gas caps, one entry per auction) and only then asks the NEAR MPC network to sign for that agent's Ethereum address. You can pause every agent at once.

Agents

On Ethereum, each agent is an address derived from the vault account and the agent's path. Nobody holds its private key. No wallet pop-ups: each agent encrypts its bid and asks the vault; the vault gets it signed, or refuses. On-chain, other bidders, the seller and the contract only ever see ciphertexts.

5Close, reveal, settle

Closing computes the outcome under encryption and marks only two values as publicly decryptable: the winner and the price (2nd-highest bid, or the reserve). Losing bids stay sealed forever.

The winning agent (or each pool member, for its share) asks the vault; the vault checks the seller allowlist and the agent's spending limit, then calls mt_transfer on intents.near.
